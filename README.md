# ✣ DAN TATTOO (@danzauutattoo) - Website Oficial

Landing Page & Portfólio Interativo para o tatuador **DAN** ([@danzauutattoo](https://www.instagram.com/danzauutattoo/)), localizado em **Brasília • Asa Norte** no *Tattoo Honey Studio*.

---

## 🎨 Características do Projeto

- **Hero Glassmorphism**: Visual moderno com paleta dark, efeitos de luz, badges de autenticidade, métricas e marquee de especialidades (*Cyber-Sigilism*, *Fine Line*, *Dark Anime*, *Luas Carmesim*).
- **Carrossel 3D de Flashs & Tatuagens**: Visualização em perspectiva 3D das artes autorais e fotos reais com botão direto de reserva no WhatsApp com a arte selecionada.
- **Destaques do Instagram**: Stories interativos inspirados no perfil (*✣ flashs ✣*, *✣ disponíveis...*, *cicatrizadas*, *tattoos*, *feedbacks*).
- **Simulador de Orçamento**: Configurador interativo para escolha de local do corpo, tamanho estimado e estilo, gerando mensagem pronta para o WhatsApp.
- **Botão Flutuante de WhatsApp**: Ícone oficial 3D com status online em tempo real e popover de mensagens rápidas.
- **Sobre o Artista**: Seção destacando o estúdio privativo na Asa Norte, biossegurança hospitalar e foco no conforto do cliente.

---

## 🛠️ Tecnologias Utilizadas

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS** (Tema Dark, Glassmorphism, Efeitos Neon/Crimson)
- **Lucide Icons**
- **Design Totalmente Responsivo** (Mobile / Tablet / Desktop)

---

## 🚀 Como Rodar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Executar o servidor de desenvolvimento
npm run dev

# 3. Gerar build de produção
npm run build
```
